# UMGC Open House Website (Demo)

## Project Overview

This project is a demo website created to practice front-end web development using HTML and CSS.

The website simulates an open house event for the University of Maryland Global Campus (UMGC), where prospective students can view event information and access an RSVP registration form.

**Disclaimer:** This is an unofficial, educational project created for personal practice and portfolio purposes. It is not affiliated with or endorsed by UMGC. All event details are fictional.

## Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## Features

- Responsive layout for desktop and mobile devices
- Navigation menu with links to different sections
- Event details and information
- Photo placeholders for future images
- RSVP button designed to link to Microsoft Forms

## Project Purpose

The purpose of this project is to strengthen my front-end development skills, particularly in:

- Structuring web pages using semantic HTML
- Styling layouts with CSS
- Creating responsive designs
- Improving website navigation and user experience
- Integrating links to external services

## Future Improvements

- Add event photos and graphics
- Connect the RSVP button to a demo Microsoft Forms registration page
- Improve mobile responsiveness
- Add JavaScript for interactive features
